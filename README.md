# 高三16班 · 班级工作台

班级内部数据工作台（GitHub Pages 托管），**教师自用，无需口令**。

- 支持多场考试切换：高二上期中 / 高二上期末 / 高二下期中 / 高二下期末 / 高三进班 / 高三第一次月测 / 高三第二次月测 / 高三期初联考 / 第三次监测（共 9 场，首场 高二上期中 为对比基线）
- 数据源：qichu_core(高三4场) + third_core(第三次监测) + extra_exams(高二4场)
- 打开后自动校验版本，发现新版本会在顶部提示刷新，**保证老师看到最新版**。

## 本地数据说明（仅存教师本机浏览器）

作业 / 积分 / 点名 / 培优备注与记录 / 谈心 全部保存在老师自己浏览器（localStorage），不上传服务器。
换电脑或清缓存前，请在各页面点「⬇ 导出全部备份」保存 JSON，新环境用「⬆ 导入」恢复。

## 下次更新（老师只需把数据给 AI，由 AI 重新构建部署）

- **下次考试**：把新成绩补充进 qichu_core / third_core / extra_exams 对应数据源，把考试名加入 `build_site.py` 的 `EXAM_ORDER`，重跑 `build_site.py` 即可。
- **下次调座位**：直接修改 `build_site.py` 里的 `seat` 字典（rows 每排9人、front 讲台左右两人），重跑脚本。
- 任何改动都会自动生成新 `BUILD`，老师打开页面会收到「发现新版本」提示。
